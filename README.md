# Food of Fortune 🎡

Unsere Fast-Food-Challenge in Kalifornien: Ketten abhaken, die nächsten offenen Ketten in der Nähe finden und per Glücksrad (mit Lily) entscheiden, wohin es als Nächstes geht.

**App starten:** https://sebojo.github.io/food-of-fortune/

- Filialdaten: © OpenStreetMap-Mitwirkende (Overpass API), Adresssuche über Nominatim
- Häkchen werden nur lokal im Browser gespeichert
